# Security Policy

## Supported Versions

We provide security updates for the following versions of SwitchBack:

| Version | Supported          |
| ------- | ------------------ |
| Latest Release (Main Branch) | :white_check_mark: |
| Older Releases               | :x:                |

## Reporting a Vulnerability

We take the security of SwitchBack seriously. If you discover a security vulnerability or potential privacy issue in SwitchBack, please report it to us responsibly instead of opening a public issue.

### How to Report

* **Email:** Send details of the issue to `security@jaistudio.com` (or create a Private Vulnerability Advisory on GitHub).
* **Details to Include:**
  * Steps to reproduce the issue
  * Affected components or hooks
  * Operating system version (Windows 10 / 11)
  * Any proof-of-concept code or details

### Response Timeline

* We will acknowledge receipt of your report within 48 hours.
* We aim to validate and provide a remediation plan within 5 business days.
* A public fix and security advisory will be released once patched.

## Privacy & Security Guarantees

* **100% Local Execution:** SwitchBack runs entirely on your local machine.
* **No Telemetry / No Tracking:** SwitchBack does not transmit your prompts, terminal output, or workspace data to any external server.
* **Local Network Only:** The Mobile Remote server communicates strictly over your local Wi-Fi network (`LAN`).
